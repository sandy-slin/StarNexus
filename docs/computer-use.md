# Computer Use 与飞书验收

## 目标确认

- 确认 Computer Use 连接的是 MacBook Pro2，而不是当前开发机或其他远程窗口。
- 飞书目标必须是 `Her remote · Pro`；窗口可能显示 `Her remote · Lin’s MacBook Pro`。不要误发给“林森的her”。
- 真实消息、菜单和群聊验收只在目标机器的飞书窗口中进行。

## 操作节奏

- 首次使用或重置后先调用一次 `getState()`。
- 应用名称解析失败时用 bundle id，例如 `com.electron.lark`。
- 每次操作后重新读取 `getAXState()`，只使用最新元素编号。
- 原生应用优先用可访问性元素；目标不清楚时用截图辅助。
- 打开指定私聊或群时用飞书客户端协议：`open "lark://applink.feishu.cn/client/chat/open?openChatId=<chat_id>"`。不要用 `open "https://applink.feishu.cn/..."`，它会先在默认浏览器里弹出「即将在飞书中打开」中转页，打断林森当前的窗口。
- 不要在会话列表里点选聊天：列表随新消息不断重排，坐标点击很容易打开别人的群（实测误开过「对外材料整理」和日历）。一律用上面的 `lark://` 链接打开。
- 观察到最终结果后停止操作，并只调用一次 `completion_summary`。

## 卡片按钮点击

- 飞书卡片按钮（审批卡「同意，去做」、选项按钮等）用可访问性元素编号点击**不会触发卡片回调**，服务端收不到；必须用坐标点击 `app.click([x, y])`。
- 坐标空间等于截图的**实际像素**，不等于截图在对话里显示的尺寸。先解析截图字节拿到真实宽度（PNG 读 IHDR，JPEG 读 SOF 段），再按 `实际坐标 = 显示坐标 × (实际宽度 / 显示宽度)` 换算。显示尺寸会变，倍数要每次重新算（2026-11-17 实测：先是约 1.3 倍，后来截图实际 2596 宽、显示约 800 宽，倍数变成约 3.245；用错倍数会点进会话列表）。
- 点完先看截图里鼠标指针落在哪，与目标按钮对比，偏了就重新算倍数，不要连续盲点。
- 每次点卡片按钮后，用 `grep -nE "收到卡片点击|状态卡 点击|会话审批|选项按钮|会话管理" ~/.carher-feishu-agent/logs/agent.log | tail` 确认服务端收到；客户端卡片变色（如「✅ 已同意」）才算点中。
- 点歪了可能误触旁边的按钮（例如把旧卡片的「不建了」点掉）。点之前确认截图里目标按钮附近没有别的可点元素。
- 服务端日志不记普通命令（如 `/help`）。判断「服务是否还在收消息」要看私聊里机器人有没有回复，不要只看日志里有没有新行。

## 与林森共用这台 Mac

- 林森可能同时在用这台 Mac。每次界面操作前先检查空闲时间：`ioreg -c IOHIDSystem | awk '/HIDIdleTime/ {print int($NF/1000000000); exit}'`，空闲 ≥ 90 秒再动；不够就轮询等待，不要抢鼠标。
- 工具提示 “The user changed '/Applications/Lark.app'” 表示林森刚操作过飞书。先重新读取界面状态，确认当前打开的是哪个聊天，再继续。
- 输入框里出现不是自己输入的草稿（例如别的群里的半句话），不要发送、不要清空，留给林森处理并在记录里标红。

## 飞书验收顺序

1. 打开 `Her remote · Pro` 私聊并确认发送对象。
2. 发送最小测试消息，确认机器人回复。
3. 执行目标功能，例如 `/ns codex ~/work/test1115`。
4. 核对目标目录、新群、首轮结果和群内续聊。
5. 验证写权限时创建测试文件并读取内容确认。
6. 菜单更新后重新进入或刷新私聊，确认菜单文字实际出现。

## 失败判定

- `ScreenCaptureKit SCStreamErrorDomain -3811/-3812` 表示屏幕捕捉链路失败；不能把点击返回或服务端 API 成功当成 UI 验收成功。恢复后必须重新读取目标窗口。
- 遇到 -3811 先分清范围：对访达执行 `getApp("com.apple.finder")` 并截图；访达能截、飞书不能截，就是飞书窗口一侧的问题（2026-11-17 下午实测，飞书会议纪要等独立窗口在前台时持续出现）。命令行 `screencapture -x /tmp/x.png` 能成功，只说明系统录屏权限正常。
- 恢复手段：结束 `SkyComputerUseService` 进程（它会自动重启），再 `js_reset` 和 `getApp`；仍失败就等林森空闲后再试。截图恢复前可以用 `getAXState` 读文字确认结果，但卡片按钮必须等截图恢复后再按坐标点。
- accessibility tree 没变化时先做明确操作或改用截图 / 全量树，不要无间隔重复读取。
- 只读到历史消息只能证明历史存在，不能证明本次操作成功。
- `cgWindowNotFound -10005` 表示暂时拿不到飞书窗口（常见于林森正在切换或使用窗口）；先停下界面操作，稍后重新 `getApp`，不要连续重试。
